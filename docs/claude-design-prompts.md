# Claude Design 프롬프트

요구사항 원본: [MyMail 요구사항 정의서](https://claude.ai/code/artifact/b1969ba7-ba7b-4db1-b06f-ed97e49959ab) 6장

진행 순서: 1차(메인 화면 + 토큰)를 먼저 확정한 뒤 후속 프롬프트를 하나씩 요청한다.

## 1차: 메인 화면 + 디자인 토큰

```
Windows용 데스크톱 메일 클라이언트 "MyMail"의 메인 화면을 디자인해줘.
Tauri + React로 구현할 예정이라 웹 기술(CSS)로 그대로 옮길 수 있는 디자인이어야 해.

## 제품
- Gmail 개인 계정과 네이버 메일 계정을 여러 개 등록해서 한 앱에서 보는 메일 앱
- 사용자는 나 혼자(개인용), UI 언어는 한국어만
- 스타일: Superhuman, Spark, Linear 같은 미니멀한 모던 웹앱. 테두리·그림자·색 면은 최소화하고 여백과 글자 굵기로 위계를 줘

## 레이아웃 (4단, 프레임 없는 창)
- 타이틀 바(높이 40px): 왼쪽 MyMail 로고, 가운데 검색창("메일 검색", 단축키 / 표시), 오른쪽 동기화 상태 아이콘·설정·창 버튼(최소화/최대화/닫기)
- ① 계정 레일(64px 고정)
  - 맨 위 "전체"(통합 받은편지함) 아이콘, 구분선, 그 아래 계정 아바타 세로 나열, 맨 아래 계정 추가(+)와 설정
  - 아바타: 40px 원형, 이니셜 또는 사진, 계정 고유 색 링, 오른쪽 아래 서비스 배지(Google/네이버), 오른쪽 위 안 읽은 수 배지(99+)
  - 선택된 계정은 왼쪽 세로 막대로 표시. 호버 시 이메일 주소 툴팁
- ② 폴더 패널(기본 220px)
  - 상단에 선택 계정 이름·주소, "새 메일" 버튼
  - 받은편지함·보낸편지함·임시보관함·스팸·휴지통, 그 아래 라벨/사용자 폴더 트리(라벨은 색 점). 각 항목에 안 읽은 수
- ③ 메일 목록(기본 360px)
  - 상단 툴바: 전체/안 읽음/별표 필터, 정렬, 새로고침
  - 행: 안 읽음 점, 보낸사람(안 읽음이면 굵게), 시간, 제목, 미리보기 1줄, 첨부·별표·라벨 칩
  - 호버 시 체크박스와 빠른 동작(보관·삭제·읽음·별표)
- ④ 본문(나머지, 최소 480px)
  - 제목, 보낸사람 아바타·이름·주소, 받는사람(펼치기), 시간
  - 동작 버튼: 답장·전체 답장·전달·보관·삭제·더보기
  - 외부 이미지 차단 배너("이미지가 차단되었습니다 · 표시 · 이 보낸사람은 항상 표시"), 첨부 카드(형식 아이콘·이름·크기·저장)
  - 스레드의 이전 메일은 한 줄로 접힘. 맨 아래 "답장 쓰기…" 인라인 입력
- 패널 너비 조절
  - 폴더|목록, 목록|본문 경계를 좌우로 드래그해 너비 조절(폴더 180~320px, 목록 300~520px)
  - 경계에 호버하면 좌우 화살표 커서 + 2px 강조선, 더블클릭하면 기본 너비
  - 폴더 패널을 최소보다 더 줄이면 아이콘만 남고 접힘. 이 핸들의 호버 상태도 보여줘

## 스타일 가이드
- 글꼴: Pretendard. 본문 14px, 목록 보낸사람·제목 14px, 보조 12px, 메일 제목 20px
- 색: 중립 회색 바탕 + 강조색 1개. 계정 색 팔레트 8색(라이트·다크 모두 대비 4.5:1 이상)
- 모서리: 버튼·입력창 6px, 카드·팝업 10px. 간격 4px 단위. 아이콘은 20px 선 아이콘(Lucide 계열)
- 라이트·다크 모드 둘 다 같은 완성도로

## 예시 데이터
- 계정 3개: 개인 Gmail(파랑 계열), 두 번째 Gmail(초록 계열), 네이버(네이버 그린과 겹치지 않는 색)
- 한국어 메일 8~10개: 택배 알림, 카드 명세서, 지인 메일, 뉴스레터, 첨부가 있는 메일 등 현실적인 내용

## 요청 결과물
1. 메인 화면 - 개인 Gmail 계정 선택, 받은편지함, 메일 1개 열림 (라이트/다크)
2. 메인 화면 - "전체" 통합 받은편지함 선택 상태
   - 폴더 패널에는 계정별 받은편지함 목록, 목록 행 왼쪽에 계정 색 세로선 (라이트)
3. 디자인 토큰 표: 색·글꼴·간격·모서리를 CSS 변수 이름과 함께 (예: --color-bg, --color-accent, --account-1 …)
```

## 2차: 메일 작성기

```
확정한 메인 화면 스타일 그대로 메일 작성기를 디자인해줘.
- 본문 영역의 인라인 작성기와 별도 창 작성기 두 가지
- 보내는 계정 드롭다운(계정 색 표시), 받는사람·참조·숨은참조 칩 입력과 자동완성 목록
- 제목, 서식 툴바(글꼴·굵게·목록·링크·이미지), 첨부 영역(드래그 앤 드롭 중 상태 포함)
- 보내기 버튼 + 예약 발송 메뉴, "임시저장됨" 상태 문구
- 하단 토스트 "보내는 중… · 취소"
```

## 3차: 계정 추가 + 첫 실행

```
계정 추가 흐름을 4단계로 디자인해줘 (모달).
① 서비스 선택(Google / 네이버)
② Google: "브라우저에서 로그인을 완료하세요" 대기 화면
   네이버: 아이디·비밀번호 입력 + "IMAP 사용 켜기", "2단계 인증 사용 시 애플리케이션 비밀번호" 안내와 로그인 실패 상태
③ 표시 이름·계정 색 선택(8색)
④ 전체 메일 동기화 진행률(받은 메일 수 / 전체, 백그라운드로 계속된다는 안내)
그리고 계정이 하나도 없는 첫 실행 화면도 같이 만들어줘.
```

## 4차: 검색·설정·알림·상태

```
나머지 화면과 상태를 디자인해줘.
- 검색: 검색창 포커스 시 추천(최근 검색·보낸사람), 결과 목록 검색어 강조, 필터 칩(보낸사람·기간·첨부)
- 설정: 탭(일반·계정·모양·단축키). 계정 탭에서 순서·색·서명·알림 설정
- Windows 알림 토스트(계정 색·보낸사람·제목, 보관·읽음 버튼)와 트레이 우클릭 메뉴
- 상태: 로딩 스켈레톤, 빈 폴더, 메일 미선택(단축키 힌트), 오프라인 배너, 인증 오류(아바타 경고 + "다시 로그인 필요" 배너), 발송 실패
- 컴포넌트 상태 시트: 계정 아바타·폴더 항목·목록 행·버튼의 기본/호버/선택/비활성/오류
```

## 5차: Gmail 연결 방식 변경 반영 (2026-10-09)

Gmail을 OAuth 브라우저 로그인 대신 IMAP + 앱 비밀번호로 연결하기로 바꿨다. 아래를 캔버스에 넘긴다.

```
Gmail 연결 방식을 바꿨어. 브라우저 로그인(OAuth) 대신 Gmail 주소 + 앱 비밀번호로 연결해.
아래 화면만 고쳐줘. 나머지는 그대로 둬.

1. 계정 추가 모달(AddAccount) ② 단계의 Google 화면
   - "브라우저에서 로그인" 대기 화면을 없애고, 네이버 화면과 같은 구조의 입력 폼으로 바꿔줘
   - 입력: Gmail 주소, 앱 비밀번호(16자리, 4자리씩 띄어 보여주기, 표시/숨기기 토글)
   - 안내: "Google 계정 > 보안에서 2단계 인증을 켜고 앱 비밀번호를 만들어 붙여넣으세요" + "앱 비밀번호 만드는 법" 링크
   - 로그인 실패 상태: "앱 비밀번호가 맞지 않거나 2단계 인증이 꺼져 있어요" 오류 메시지
2. 첫 실행(FirstRun): "Google 계정 추가" 버튼 설명을 "Gmail · 브라우저에서 로그인" → "Gmail · 앱 비밀번호로 연결"로
3. 인증 오류 상태(States): 문구를 "앱 비밀번호를 다시 입력해 주세요"로 (버튼: "다시 연결")
```
